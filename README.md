# 가계부

수입·지출, 계좌·카드, 월 예산, 저축·투자, 고정비·구독, 연간 결산을 관리하는 다중 사용자 가계부.

- 화면: `index.html` (정적 파일, GitHub Pages로 배포)
- 로그인·데이터: Supabase (이메일 가입, Row Level Security로 사용자별 데이터 격리)
- DB 설정: Supabase SQL Editor에서 `supabase/schema.sql` → `update_v2.sql` → `update_v3.sql` 순서로 실행 (모두 여러 번 실행해도 안전)

## 데이터 보호
- 모든 테이블에 `user_id` 소유권 + RLS(본인 행만 조회·추가·수정·삭제), 로그인하지 않은 요청은 차단
- 가입 시 DB 트리거가 빈 설정과 기본 카테고리를 자동 생성
- 사이트에 들어 있는 키는 공개용(publishable) 키뿐이며, secret key는 저장소에 넣지 않음
- 계좌번호·카드번호 입력란 없음, 개인 데이터·샘플 데이터 없음

## 주요 기능
- 카테고리·그룹·세부 항목·색상·순서 직접 편집, 태그, 메뉴 표시, 한 달 시작일
- 날짜별 목록·달력 보기, 만원 단위 표시, 글자 크기, 다크모드, 도넛 차트, 지난달 대비
- 계좌 잔액 자동 연동(이체 포함), 반복 거래 자동/직접 기록, 예산 주의·초과 알림, 하루 사용 가능 금액
- 거래 복사·최근 기록 채우기, 모바일 + 버튼, CSV 내보내기, 비밀번호 변경, 회원 탈퇴(데이터 전체 삭제)
- 분석: 월간 요약, 예산 페이스, 카테고리 추이(드릴다운), 저축률·순자산 추이, 요일별·1년 히트맵, 태그별 합계
- 카드 할부, 대출·순자산, 목표 저축, 엑셀·CSV 가져오기, 전체 백업·복원, 금액 계산식, 즐겨찾기 빠른 기록, 비회원 시작·회원 전환
- 엑셀 읽기: SheetJS(xlsx.full.min.js, Apache-2.0)를 가져오기할 때만 불러옴
